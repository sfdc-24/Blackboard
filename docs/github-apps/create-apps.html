Create the two GitHub Apps

Each button opens GitHub's "Register new GitHub App" page with the settings filled in. Check the permissions, then click Create GitHub App. GitHub then opens www.sfdc24.com with ?code=... in the address bar. Copy that code and run step 2 of docs/github-apps/README.md within one hour.

A. sfdc24-cloud-clone (read-only)

Contents: read. Metadata: read. No webhook.

B. sfdc24-ccc-broker (write, owned branch and PR only)

Contents: write. Pull requests: write. Metadata: read. No webhook.
